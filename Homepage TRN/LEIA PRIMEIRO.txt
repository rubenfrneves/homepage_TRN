TRN — O QUE CARREGAR NO GITHUB (só esta pasta, mais nada)
=========================================================

Esta pasta tem tudo. Pode ignorar as outras pastas da TRN.
O site é refeito automaticamente no GitHub: só a Opção A, com backoffice e vídeo.

PASSO 1 — Definir a senha do backoffice (Terminal, uma só vez)
  a) Abra o Terminal (Cmd+Espaço, escreva "Terminal").
  b) Escreva  cd  (com um espaço no fim) e ARRASTE para a janela a pasta
     "TRN-propostas-A-B_gerador" que está dentro de "1_CARREGAR_NO_GITHUB". Prima Enter.
  c) Escreva:  python3 gerar.py --senha   e prima Enter.
  d) Escreva a senha (mínimo 12 caracteres; não aparece enquanto escreve) e repita.
     O utilizador do backoffice é: ADMIN TIC
  Fica criado o ficheiro content/admin.json dentro dessa pasta.

PASSO 2 — Carregar no GitHub (Safari/Chrome)
  a) Abra o repositório https://github.com/rubenfrneves/trn-proposta-site
  b) Add file → Upload files.
  c) No Finder, ARRASTE a pasta "TRN-propostas-A-B_gerador" (a pasta inteira, a partir de
     "1_CARREGAR_NO_GITHUB") para a caixa. Espere que termine e carregue em Commit changes.

PASSO 3 — Criar a tarefa automática
  a) No repositório: Add file → Create new file.
  b) No nome escreva exatamente:  .github/workflows/publicar.yml
  c) Abra o ficheiro "2_COLAR_NO_GITHUB_publicar.yml.txt", copie TODO o texto e cole na caixa grande.
  d) Commit changes.

PASSO 4 — Ligar o GitHub Pages à tarefa automática
  Settings → Pages → "Source": escolha  GitHub Actions.
  Espere 2 a 3 minutos (separador Actions: deve ficar com visto verde).
  O site fica em:  https://rubenfrneves.github.io/trn-proposta-site/TRN-propostas-A-B/
  Backoffice:      https://rubenfrneves.github.io/trn-proposta-site/TRN-propostas-A-B/admin/

PASSO 5 — Token para publicar a partir do backoffice (uma só vez)
  GitHub → o seu perfil → Settings → Developer settings → Personal access tokens →
  Fine-grained tokens → Generate new token.
  - Repository access: só "trn-proposta-site".
  - Permissions → Contents: Read and write (e Actions: Read-only, opcional).
  Copie o token e cole-o no backoffice quando for pedido.
