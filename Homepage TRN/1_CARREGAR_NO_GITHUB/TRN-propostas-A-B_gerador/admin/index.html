Backoffice por configurar

Ainda não foi definida a senha de acesso. No computador, na pasta do gerador, execute:

python3 gerar.py --senha

Depois envie o ficheiro content/admin.json para o GitHub. As instruções completas estão no LEIA-ME-BACKOFFICE.md.

Ligar ao GitHub

Para publicar alterações, o backoffice usa um token do GitHub só com permissão neste repositório. Cola-o aqui uma vez: fica guardado cifrado com a sua senha neste navegador.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: só .
  3. Permissions → Repository permissions → Contents: Read and write (e Actions: Read-only, opcional, para ver o estado da publicação).
